# SKILLTRACK — Personal Skill Development Dashboard

A premium, fully interactive frontend-only skill tracker built with pure HTML, CSS & JavaScript.

**Live Demo:** Deploy this repo on Vercel in one click.

## Features

- **Dashboard** — Overview stats, progress ring, weekly chart, today’s goals & recent activity
- **My Skills** — Add / Edit / Delete skills with proficiency, progress %, target date & notes
- **Coding Tracker** — Log problems from LeetCode, HackerRank, CodeChef, GFG etc.
- **Study Timer** — Real working stopwatch with skill selection & session saving
- **Goals** — Set targets, track hours, mark complete, see overdue goals
- **Projects** — Track personal projects with tech stack, GitHub & live links
- **Analytics** — Charts, difficulty breakdown, activity heatmap, key metrics
- **Settings** — Profile, light/dark theme, export JSON/CSV, reset data

## Tech

- Pure HTML + CSS + Vanilla JavaScript
- Chart.js (CDN)
- Lucide Icons (CDN)
- LocalStorage for persistence
- No backend, no database, no auth

## Deploy on Vercel

1. Go to [vercel.com](https://vercel.com) → New Project
2. Import this GitHub repository
3. Framework Preset: **Other**
4. Click **Deploy**

That’s it. No environment variables needed.

## Local Usage

Just open `index.html` in any modern browser, or use a simple static server:

```bash
npx serve .
```
